This video is a continuation of previous videos PE #121 and PE #122. We continue with the analytical modelling of the buck converter in CCM by showing how to derive an analytical small-signal model of the converter from which any small-signal transfer function can be calculated. The video also shows how to implement this model in Qspice in order to be able to obtain the Bode plots of the different transfer functions by simulation.
